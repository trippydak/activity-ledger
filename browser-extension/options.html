Visit a regular website in a focused window for a few seconds, then return here. This settings page is excluded, so its current state is normally “Browser or extension page excluded.” If Edge is reporting as Chrome, select Microsoft Edge above and save.

To include a private-mode flag, open this extension's Details at edge://extensions or chrome://extensions and manually enable Allow in InPrivate or Allow in Incognito. The flag says only that private browsing is active. Private addresses, titles, and page contents are never collected. Until that permission is enabled, private-mode flags are unavailable.

What gets recorded

The active HTTP(S) website in the focused regular browser window, website popup, or supported installed web app is reported. Private / InPrivate windows can report only a private-mode flag after you explicitly allow the extension in private mode; no private tab is queried. Background tabs, browser settings, and extension pages are excluded from website recording. The desktop app controls saved detail and exclusions.

No page contents, passwords, keystrokes, or screenshots are captured. Your desktop app stores the activity locally.
